# SkillSetu — Execution Tasks: Portfolio & Analytics

## Task 1 — Portfolio Data Model Wiring
Auto-create `portfolio_items` entries whenever a skill is verified, a certification/program is completed, an internship is completed, or an achievement is recorded.

## Task 2 — Student Portfolio View
Display verified skills, certifications, projects, internships, and achievements in one page.

## Task 3 — Portfolio Export/Share
Generate a shareable/exportable version of the portfolio (PDF or public link).

## Task 4 — Student Personal Dashboard
Applications status, recommended opportunities, skill-gap summary, enrolled programs — in one view.

## Task 5 — Industry Dashboard: Applicant Funnel
Visualize applicant counts per stage (applied → shortlisted → interview → offer) per posting.

## Task 6 — Industry Dashboard: Skill-Demand Trends
Chart of which required skills are trending up/down across the industry's own postings (feeds the Task 8 aggregation from the skill-engine tasks).

## Task 7 — Institution Dashboard: Participation & Placement Progress
Student counts by: assessment completed, internships applied/ongoing/completed, placement status.

## Task 8 — ⭐ Institution Dashboard: Curriculum Feedback View
Surface the cross-referenced "skill gap vs. industry demand" report (built in skill-engine Task 9) directly on the institution dashboard, with drill-down by department/batch — this is the primary evaluator-facing view of the USP.

## Task 9 — Audit Log Views
Admin-facing view of key actions (postings created, status changes) for accountability.

## Task 10 — Cross-Role Analytics Summary
A top-level "at a glance" analytics panel combining participation, placement, and curriculum-feedback signals for institution admins.
