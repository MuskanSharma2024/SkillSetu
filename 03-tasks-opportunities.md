# SkillSetu — Execution Tasks: Opportunities & Applications

## Task 1 — Opportunity Posting (Industry)
Form + endpoint for industry to post internships/jobs/apprenticeships/projects with required skills and deadline.

## Task 2 — Opportunity-Skill Linking
Many-to-many mapping between an opportunity and required skills (with minimum proficiency per skill).

## Task 3 — Opportunity Browse & Search (Student)
Search/filter opportunities by skill, type, location, deadline.

## Task 4 — Matched Recommendations View
Show student a ranked list of opportunities using the Recommendation Engine (from skill-engine tasks).

## Task 5 — Apply Flow
Student applies to an opportunity → creates `applications` row with computed match score.

## Task 6 — Application Tracking (Student Side)
Student view of all applications with current status (applied / shortlisted / interview / offered / rejected / completed).

## Task 7 — Candidate Shortlisting (Industry Side)
Industry view of applicants sorted by match score + eligibility; ability to update status.

## Task 8 — Mentor Feedback & Completion Record
On completion, mentor/recruiter submits feedback; stored against the application and surfaced to portfolio.

## Task 9 — Learning Program Posting (Industry)
Companies publish training/certification/workshop/mentorship programs with skills covered.

## Task 10 — Program Enrollment (Student)
Student browses and enrolls in learning programs; track enrollment status.

## Task 11 — Program Completion → Skill Profile Update
On program completion, update the student's `skill_profiles` with the newly verified skill.

## Task 12 — Academic Opportunities (Faculty)
Post/browse faculty internships, FDPs, consultancy, and research collaboration listings; academician apply flow + status tracking.
